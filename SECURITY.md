# Security

Report an AssetFare vulnerability privately to `security@assetfare.dev` with
the affected source commit, deployed address, impact, and reproduction. Do not
send private keys, seed phrases, session tokens, or funds.

Prefer local forks and read-only RPC evidence. Do not move third-party assets,
degrade availability, or submit transactions without explicit authorization.
There is no standing paid bounty promise unless separately agreed in writing.
